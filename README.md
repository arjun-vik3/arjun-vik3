## 🔎 Planned Forensic Investigations

### CASE-001 — Windows Login Activity Investigation
**Objective:** Examine Windows authentication events to identify failed logins, successful logins, and potentially suspicious activity.

- Review Windows Security Event Logs.
- Examine Event IDs 4624 and 4625.
- Correlate timestamps and available account information.
- Document observations and investigation limitations.

**Status:** Planned

### CASE-002 — Email Phishing Investigation
**Objective:** Examine a sample phishing email and identify indicators that may help determine whether it is suspicious.

- Analyze email headers and sender information.
- Review SPF, DKIM and DMARC results where available.
- Examine URLs and attachment metadata safely.
- Document indicators of compromise and findings.

**Status:** Planned

### CASE-003 — Microsoft 365 Audit Investigation
**Objective:** Explore how Microsoft 365 audit records can support investigations into suspicious account and data-access activity.

- Review relevant audit records.
- Investigate available user, activity, and timestamp information.
- Explore file-access and sharing events.
- Document findings and evidence limitations.

**Status:** Planned

### CASE-004 — Digital Evidence Integrity
**Objective:** Learn how forensic evidence is documented and protected against unnoticed modification.

- Calculate cryptographic hashes.
- Record evidence metadata.
- Maintain an evidence handling log.
- Document the steps used to preserve integrity.

**Status:** Planned
